# MSPC-GreenAI 系统设计方案

## 一、系统目标

MSPC-GreenAI 将“钢渣基镁磷水泥透水建材”从单一材料成果升级为“材料研发 + AI 设计 + 工程决策 + 低碳评估”的智能化应用平台。

系统不依赖大规模训练数据，而采用更适合当前阶段的路线：

```text
专家规则约束 + 半经验性能评估 + 硅基流动大模型解释生成 + 后续实验数据闭环
```

## 二、系统定位

系统面向四类用户：

1. 比赛评委：快速理解项目技术亮点、工程价值和 AI 结合方式。
2. 工程方：输入场景后获取材料方案、施工建议和低碳效益。
3. 团队成员：用于答辩问答、方案生成和实验数据沉淀。
4. 后续合作企业：用于项目推广、材料选型和前期方案比选。

## 三、核心模块

### 1. AI 项目知识问答

让系统像项目答辩助手一样回答：

- 为什么使用钢渣？
- 为什么使用镁磷水泥？
- 为什么 25% 孔隙率重要？
- 最优工况是什么？
- 适合哪些工程场景？

### 2. 智能配方推荐

用户输入：应用场景、强度需求、透水需求、施工方式、成本优先级。

系统输出：钢渣粒径、成型方式、孔隙率范围、水胶比、骨料胶凝比、推荐理由。

### 3. 半经验性能评估

系统基于项目规律估算：

- 28d 抗压强度
- 抗折强度
- 透水系数
- 综合评分
- 风险提示

### 4. 工程应用方案生成

输入工程类型、面积、厚度、地点和目标，自动生成推广/答辩可用方案。

### 5. 节能减排测算

按工程体积计算钢渣消纳量、天然骨料替代量，并输出低碳价值说明。

### 6. 实验数据闭环升级

后续真实实验数据可持续录入，用于校准规则参数，并升级为“规则 + 残差学习”的数据驱动模型。

## 四、规则核心

系统内置以下项目规律：

```text
综合最优工况：中粒级钢渣 5.0–10.0mm + 振动成型
最优孔隙率：约 25%
推荐水胶比：0.16
推荐骨料胶凝比：4.8
典型最优性能：28d 抗压强度约 41.5MPa、抗折强度约 8.0MPa、透水系数约 7.0mm/s
钢渣消纳量：约 1700kg/m³
```

## 五、技术架构

```text

       ↓

       ↓

       ↓

       ↓
页面展示 / API 输出 / 后续小程序接入
```

## 六、答辩表述

> 本项目构建了 MSPC-GreenAI 钢渣基镁磷水泥透水建材智能设计与应用决策系统。系统以项目已有实验规律和材料机理为核心，融合硅基流动大模型 API，形成“专家规则约束 + 半经验性能评估 + 工程方案生成 + 节能减排测算”的智能化应用体系。用户输入工程场景、强度需求、透水需求和施工条件后，系统可自动推荐钢渣粒径、成型方式、孔隙率控制范围和施工方案，并生成工程应用报告与低碳效益分析。现阶段系统为规则约束型 AI 原型，后续可接入正交试验数据库，升级为数据驱动的材料智能设计平台。
